# 16 示例配置与数据协议

本章把前述设计串成一份可作为实现起点的配置和数据示例。字段是建议协议，开发时应转为 Pydantic 模型并生成 JSON Schema。

```text
    ├── manifest.yaml
    ├── commit.txt
    ├── diff.ref
    └── evaluations/
```

实体目录可作为导出视图；数据库和内容寻址存储仍是在线事实源。

## 16.9 实现检查清单

- 所有 ID、时间和哈希由控制器生成或复算。
- JSON 先规范化再计算哈希。
- 所有模型输出经过严格 schema 校验。
- 所有代码候选绑定完整 Git SHA。
- 所有 task score 绑定 task snapshot 和评分镜像摘要。
- 所有裁决绑定规则版本与输入 scorecard 哈希。
- 所有历史引用都能解析到事件、产物、代码或指标。
- 任何缺失引用都会阻止晋升。
