# 14 部署运维与成本

## 14.1 环境分层

### 本地开发

单进程控制器、SQLite、本地产物、Docker，使用 5–10 个合成任务验证闭环。

### 实验环境

控制 API、队列 worker、PostgreSQL、对象存储和隔离运行节点。支持并发 trial、预算封顶和失败恢复。

### 生产评测环境

使用冻结镜像、严格网络策略、独立评分节点、审计存储和只读版本仓库。生产任务的部署与自进化实验分离。

## 14.2 Worker 队列

推荐队列划分：

```text
task-runner       高并发、长时、非可信代码
teacher           低并发、读密集、模型调用
evolution         低并发、可写 harness worktree
contract-test     短时、CPU 密集
evaluator         可信评分、严格隔离
indexer           可重试后台任务
```

评测 worker 不与任务 runner 共享可写卷或凭证。

## 14.3 关键 SLI

### 闭环健康

- 迭代从计划到裁决的成功率和耗时；
- 各状态停留时间；
- trial 基础设施失败率；
- 候选验证失败率；
- 评测重跑率和结果缺失率。

### Agent 行为

- 任务成功率及任务族分布；
- token、模型调用、工具调用和时间；
- 重复命令、上下文截断和 finalize 循环；
- champion 与 challenger 的回归数量。

### 数据完整性

- 事件序列缺口；
- 产物哈希失败；
- 无来源 scorecard；
- 无法重放的 promotion decision。

## 14.4 告警

```text
P0：隐藏数据访问、凭证泄漏、沙箱逃逸迹象
P1：champion 指针冲突、评分器异常、事件源不可用
P2：基础设施失败率连续超阈值、队列严重积压、预算异常增长
P3：索引延迟、单个任务重复失败、非关键报表缺失
```

事件源不可用时停止新 trial；索引不可用时可以继续写原始事件并延迟查询。

## 14.5 成本模型

一次迭代成本：

\[
C = C_{search} + C_{teacher} + C_{edit} + C_{smoke} + C_{promotion} + C_{retest} + C_{infra}
\]

其中搜索和晋升 trial 通常占主要部分。每个候选报告：

- 生成候选的外层成本；
- 候选执行任务的内层成本；
- 完整晋升验证成本；
- 预估的长期单任务节省或增加。

不能用“候选单次运行 token 更少”替代整个搜索过程的成本报告。

## 14.6 降本策略

按可信度从高到低使用：

1. 契约测试和静态门禁提前淘汰无效候选。
2. 先跑小型冒烟集，再跑完整晋升集。
3. 复用配置哈希完全一致的 champion 结果。
4. 任务按诊断目标分层采样，同时保留回归任务。
5. 只对边界候选增加重复 trial。
6. 对教师提供索引和局部证据读取，避免塞入完整轨迹。
7. 产物内容寻址去重和压缩。

不要通过减少关键回归任务或混用搜索与最终测试来降低成本。

## 14.7 容量估算

用以下参数估算：

```text
T = 每轮任务数
R = 每任务平均重复次数
E = 每个 trial 平均事件数
A = 每个 trial 原始产物字节
K = 每日候选数

每日 trial ≈ T × R × K
每日事件 ≈ T × R × K × E
每日原始存储 ≈ T × R × K × A
```

容量计划应给 promotion retest、失败日志和候选源代码留余量。

## 14.8 版本发布与回滚

实验晋升只更新实验的 champion。若要用于真实开发任务，另建发布流程：

```text
promoted candidate
→ 最终测试
→ 安全与人工审查
→ 生成 release artifact
→ 灰度流量
→ 生产指标监控
→ 全量或回滚
```

回滚指向已验证 release，不从当前工作区现场拼装旧代码。

## 14.9 灰度监控

生产灰度比较：

- 用户任务完成率和人工返工率；
- token、时间、工具错误和中止率；
- 按仓库语言、规模和任务类型的分层表现；
- 权限拒绝与异常命令；
- 相对旧版本的严重回归。

线上指标不能直接回流为训练或搜索证据，除非完成脱敏、授权和任务定义转换。

## 14.10 运行手册

至少准备：

- 模型供应商故障与限流处理；
- 沙箱节点不可用；
- 评测结果不一致；
- champion 指针恢复；
- 产物库损坏或引用丢失；
- 异常成本增长；
- 凭证泄漏和候选越权；
- 数据快照撤回。

每个手册写清触发条件、立即动作、数据保护、恢复验证和复盘产物。
