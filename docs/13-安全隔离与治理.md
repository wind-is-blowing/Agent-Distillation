# 13 安全隔离与治理

## 13.1 信任边界

系统默认将以下内容视为非可信：

- benchmark 目标仓库及其文档；
- shell 输出、测试日志和网页内容；
- 教师和学生生成的自然语言与代码；
- 历史经验摘要；
- 候选 harness 及其依赖声明。

控制器、权限引擎、预算核算、事件写入、评测器和隐藏数据位于可信边界。

## 13.2 权限矩阵

| 能力 | 任务学生 | 教师 | 改造学生 | 评测器 |
|---|---:|---:|---:|---:|
| 读任务工作区 | 是 | 轨迹引用 | 否 | 干净副本 |
| 写任务工作区 | 是 | 否 | 否 | 临时评分区 |
| 读 harness 源码 | 当前版只读 | 是 | 父版与白名单 | 当前候选只读 |
| 写 harness | 否 | 否 | 白名单 | 否 |
| 读隐藏测试 | 否 | 否 | 否 | 是 |
| 写元数据库 | 事件 API | 否 | 事件 API | 评分 API |
| 外网 | 按任务策略 | 默认否 | 默认否 | 默认否 |
| 修改 champion | 否 | 否 | 否 | 否，PromotionEngine 执行 |

## 13.3 沙箱要求

最低要求：

- 非特权用户、只读根文件系统；
- 精确的只读/可写挂载；
- CPU、内存、进程数、文件大小和墙钟限制；
- 默认禁用宿主 socket、Docker socket 和设备访问；
- 网络域名和端口 allowlist；
- 临时凭证只在需要的会话注入；
- 会话结束立即撤销凭证并销毁可写层；
- 宿主与容器间通过窄接口交换产物。

运行来源不明的仓库时，生产环境应使用比普通共享 Docker 更强的隔离后端。

## 13.4 防提示注入

提示注入不能只靠一句“忽略恶意指令”。系统采用结构性防护：

- 将证据放入标记为 data 的字段，与系统规则分离；
- 教师只拥有读取工具，无法通过文本获得写权限；
- 工具调用由运行时策略校验，模型文字不能授权自己；
- 经验检索结果保留来源和非可信标签；
- 对仓库中的 `AGENTS.md` 等本地规则先由控制面确定适用范围，再传给任务学生；
- 敏感操作从工具集合中移除，而不是要求模型自律。

## 13.5 防评分作弊

静态与动态检查结合：

- 扫描 benchmark 名称、任务 ID、答案片段和隐藏路径；
- 禁止候选访问评分进程、结果文件和控制数据库；
- 评分在新环境应用 `task_patch.diff`，不复用 Agent 容器；
- 检查 task patch 是否修改测试或评测脚本；
- 候选运行时不提供可伪造的“pass”接口；
- 对异常高提升、仅命中特定任务的分支和环境探测行为触发人工审计；
- 在保留任务和变体任务上检测硬编码。

## 13.6 机密与隐私

- 不把宿主全部环境变量传入沙箱；
- 凭证通过最小作用域临时令牌提供；
- 日志写入前脱敏，原始敏感产物按更高等级加密和限权；
- 教师证据包默认排除用户源代码中的秘密文件；
- 产物下载和查询写审计日志；
- 配置中只保存 secret 引用，不保存值。

## 13.7 供应链

候选默认不能新增依赖。允许新增时：

- 锁定版本和哈希；
- 使用内部镜像或 allowlist registry；
- 生成 SBOM；
- 扫描已知漏洞和恶意包；
- 禁止安装脚本访问非必要网络；
- 评测镜像按 digest 固定。

## 13.8 审计

必须审计：

- 谁创建、暂停或修改实验配置；
- 哪个模型配置读取了哪些证据；
- 候选修改了哪些文件；
- 权限引擎允许或拒绝的工具调用；
- 评分器使用的任务、镜像和补丁哈希；
- champion 的每次切换与回滚；
- 人工覆盖、禁用和数据删除操作。

审计日志单独保留，普通候选和 Agent 无写权限。

## 13.9 风险分级

| 等级 | 示例 | 处理 |
|---|---|---|
| P0 | 候选访问隐藏测试或宿主凭证 | 立即停止实验、撤销凭证、保留现场 |
| P1 | 评分结果不可追溯、审计事件缺失 | 禁止晋升、重跑受影响评测 |
| P2 | 候选修改受保护路径、异常网络请求 | 自动拒绝候选并记录违规 |
| P3 | 提案证据不足、契约输出格式错误 | 有界修复或返回教师重做 |

## 13.10 治理策略

- 生产使用的 champion 必须来自固定 promotion rule；
- 新 benchmark、模型或工具权限变化开启新实验世代；
- 大范围搜索空间开放需记录决策和回滚方案；
- 自动晋升可以先只进入实验环境，生产发布由单独交付流程处理；
- 最终测试结果、局限和成本同时报告，避免只展示最佳成功率。
