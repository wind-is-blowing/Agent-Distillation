# Agent-Distillation
智能体蒸馏

总体架构

```text
┌─────────────────────────────────────────────────────────────┐
│                    Evolution Harness                        │
│                                                             │
│  ┌──────────────┐    ┌──────────────┐    ┌──────────────┐  │
│  │ Task Manager │───▶│ Coding Agent │───▶│ Trace Store  │  │
│  └──────────────┘    └──────────────┘    └──────┬───────┘  │
│          ▲                                       │          │
│          │                                       ▼          │
│  ┌───────┴──────┐    ┌──────────────┐    ┌──────────────┐  │
│  │ Version      │◀───│ Evaluator    │◀───│ Optimizer    │  │
│  │ Registry     │    │ & Promotion  │    │              │  │
│  └──────────────┘    └──────▲───────┘    └──────▲───────┘  │
│                              │                   │          │
│                     ┌────────┴───────────────────┴───────┐  │
│                     │       Omnigent Adapter            │  │
│                     └────────┬──────────┬──────────┬─────┘  │
└──────────────────────────────┼──────────┼──────────┼────────┘
                               ▼          ▼          ▼
                         Qwen Code      Codex    Claude Code
                          Reviewer     Reviewer    Reviewer
```

Evolution Harness 是系统的唯一控制中心。Omnigent 是一个可替换 Adapter，而不是系统核心。即使未来更换 Omnigent、直接接入 ACP，或为某个 Agent 编写专用适配器，任务、评审、优化和版本协议也不应发生根本变化。
